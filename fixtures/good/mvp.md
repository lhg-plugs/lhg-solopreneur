# MVP 范围：番茄钟专注 App

## 产品一句话
一个极简番茄钟，帮助自由职业者专注工作，2 周内上线第一个付费版本。

## 目标用户
自由职业者、远程工作者：每天需要 3 个以上专注时段、被手机打断困扰的人。

## 核心功能（P0，本期必做）
- P0 番茄计时（25/50 分钟可调，iOS/Android/Web 三端可用）
- P0 任务列表（一个任务可关联多个番茄）
- P0 专注统计（日报/周报，核心留存钩子）

## P1（二期，明确不做）
- 白噪音、主题换肤、数据导出、多端实时同步、成就徽章、排行榜
- 以上功能明确不做，列入 v2 清单，本期任何"顺手加一个"的需求都必须先过"砍范围"评审。

## 工期（2 周倒排）
- 第 1-3 天：计时器 + 任务列表
- 第 4-7 天：统计报表 + 支付接入
- 第 8-10 天：落地页 + 定价页
- 第 11-14 天：冒烟自测 + 冷启动素材，上线

## 验收标准
- 三端计时误差 < 1 秒/25 分钟；断网重连不丢番茄记录
- 从落地页到付费成功全链路可走通（测试订单）
- Definition of Done：上述三项全部通过 + 无 blocker 级审计问题

## 成功指标
- 上线 30 天：付费转化率 ≥ 3%，次日留存 ≥ 25%

## 风险与依赖
- 风险：支付渠道审核周期不可控 → 依赖项：第 1 天就提交 Stripe/支付宝签约
- 风险：一人开发无替补 → 卡点预案：P0 功能任何一项延期超 2 天，直接砍 P1 绝不延期上线

## 技术选型
- 技术栈：Flutter（三端一套代码）+ Supabase（数据库/鉴权/后端）
- 选择理由：因为一人公司人力只有 1，必须一套代码覆盖三端；Supabase 免运维，有免费额度，冷启动成本最低。
- 备选方案：Plan B 为 React Native + 自建后端（人力成本翻倍，仅当 Flutter 插件生态卡住时启用）
- 成本估算：Supabase 免费档起步，域名约 ¥70/年，首年总成本 < ¥500
- 部署方案：App 上架 App Store/Google Play，Web 版部署到 Vercel，域名已备
