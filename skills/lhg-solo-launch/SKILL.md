# lhg-solo-launch：冷启动素材与上线执行

> 目标：输出一套"上线当天直接能用"的冷启动素材包 + 执行清单。
> 核心纪律：**没有预置回复和复盘计划的上线，叫裸奔。**

## 1. 何时使用

- 产品已开发完成（或接近完成），准备上线时 → 跑本 skill
- 已上线但首日数据惨淡，想复盘补救时 → 用第 6 步
- 产品还没影 → 先回去做 lhg-solo-mvp，素材写得再好也救不了没做完的产品

## 2. 输入与输出

- **输入**：产品一句话、目标用户、定价、落地页链接（或大纲）
- **输出**：`launch.md`，包含：上线前自查、落地页大纲、推文文案、PH 文案、演示素材规划、首日清单、评论区预置回复、7 天运营复盘计划

## 3. 上线前自查（先自查，再上线）

- [ ] 核心链路冒烟：注册→核心功能→付费，全链路走一遍（测试订单）
- [ ] 定价页的价格/退款/取消条款与实际扣费一致
- [ ] 落地页 CTA 按钮都能点、都能跳转
- [ ] 移动端看一遍（一半流量来自手机）
- [ ] 跑 `python3 scripts/audit/indie_audit.py --target <文档目录>`，blocker 清零

## 4. 冷启动素材包（每样都要"直接能用"）

### 4.1 推文文案（X/微博/即刻/朋友圈）

公式：**做了什么 + 为什么做 + 现在什么样 + 行动号召**。

- 第一句讲人话（"做了 2 周，我把自己用的番茄钟做成了产品"），不说"隆重推出"
- 痛点一句话（"自由职业者每天被打断 20 次"），数字比形容词有力
- 价格大大方方写（"免费版永久免费，专业版 ¥19/月"），藏着掖着没人信
- 结尾求反馈不求转发（"欢迎试用拍砖"比"求转发"转化高）
- **红线**：不用"颠覆/革命/保证/第一"这类绝对化词，除非加"内测中"等限定

### 4.2 Product Hunt 文案（出海必备）

- **Tagline**：一句话，50 字符内，讲清"给谁解决什么"（不是"我们是谁"）
- **首条评论**： maker 第一视角——为什么做（个人痛点）、免费版政策、一句求反馈
- **预置回复**：提前写好 5 类高频问题的回复（价格/隐私/竞品对比/路线图/ bug 反馈），上线当天 3 分钟内回复每条评论

### 4.3 落地页大纲

- Hero：标题（一句话价值）+ 副标题（给谁用的）+ 主 CTA（"立即免费开始"）
- 社会证明：内测用户评价（必须真实，编造评价是红线，审计过不了）
- 定价区：三档对比，主推档标"最受欢迎"，CTA 指向注册/支付
- FAQ：至少 5 条，把"这靠谱吗""能退款吗"这类疑虑提前消灭

### 4.4 演示素材规划

- 30 秒录屏 GIF：核心流程一气呵成（注册→解决痛点→结果），无声也能看懂
- 3 张截图：最有代表性的 3 个界面
- 进阶（可选）：一条 60 秒 launch video——"一句话讲清产品"的思路：
  先写 5 句话脚本（痛点→方案→演示→价格→号召），再配画面，不需要专业剪辑

## 5. 上线首日执行清单（精确到小时）

| 时间 | 动作 |
|---|---|
| 09:00 | 落地页/支付最后检查，测试订单走一遍 |
| 10:00 | 发推文 + 即刻/朋友圈动态 |
| 12:00 | Product Hunt 提交上线（如出海） |
| 14:00 | 第一轮评论区回复（预置回复直接用） |
| 16:00 | 目标社区发帖（V2EX/Reddit/Hacker News，文案按社区调性微调） |
| 18:00 / 21:00 | 第二/三轮评论区回复 |
| 22:00 | 当天数据记录：访问/注册/付费/留资，存档 |

**渠道原则**：每个渠道文案微调，不做无脑群发；首日主攻 2-3 个渠道，
贪多等于每个都做不好。

## 6. 上线后 7 天运营与复盘

- **第 1-3 天**：逐条回复评论和私信，把 top 3 功能请求记下来（公开回复"已记入 v2 清单"是最好的运营）
- **第 4-7 天**：按反馈修 1-2 个小体验问题，发更新日志（让早期用户看到"这个人在干活"）
- **第 7 天复盘**：四个数——访问量、注册转化率、付费转化率、次日留存；
  一个结论——继续推这个产品，还是 pivot，还是杀掉。**复盘必须有结论，不许"再看看"。**

## 7. 渠道调性速查表

| 渠道 | 调性 | 文案要点 | 禁忌 |
|---|---|---|---|
| X/推特 | 直接、maker 文化 | 讲过程、晒数据、求拍砖 | 别发广告腔，加链接放评论区 |
| 即刻/朋友圈 | 生活化 | 讲个人故事，"我为什么做这个" | 别刷屏，一天一条 |
| V2EX | 技术直男 | 讲技术选型、讲踩坑，分享创造 | 标题党会被踩，广告帖删帖 |
| Reddit | 社区自治 | 先参与再发帖，按版规来 | 无脑自推会被 ban 号 |
| Hacker News | 极客硬核 | Show HN 讲技术细节 | 营销话术零容忍 |
| Product Hunt | 出海首发 | tagline 精准，评论区高频互动 | 刷票直接下架 |
| 少数派/知乎 | 干货向 | 写"怎么做出来"的长文 | 软文痕迹太重被举报 |

**通用原则**：先当 2 周潜水员再发帖；每个渠道至少改 30% 文案；
首日主攻 2-3 个渠道，贪多嚼不烂。

## 8. 冷启动急救包（首日数据惨淡时）

如果上线 24 小时注册 < 20，别慌，按顺序排查：

1. **流量问题**：帖子阅读量 < 500 → 不是产品问题，是渠道/标题问题，换渠道重发。
2. **转化问题**：阅读高、注册低 → 落地页问题，检查首屏 3 秒内能不能讲清价值。
3. **信任问题**：注册高、付费 0 → 定价页问题，检查退款/取消条款是否显眼。
4. **产品问题**：以上都正常但次日留存 < 10% → 回到 lhg-solo-idea，
   可能问题本身是伪需求，考虑 pivot。

记住：冷启动是"测试"不是"审判"，第 7 天复盘才下结论。

> 合规提醒：冷启动素材如涉及价格、收入、支付表述，须与 pricing.md 的
> 合规声明保持一致（支付与税务合规因国家/地区而异，以当地法规为准），
> 宣发文案禁用绝对化承诺，审计脚本 SOLO-CMP-003/SOLO-LCH-010 会检查。

## 9. 反模式（别踩）

1. **上线即躺平**："酒香不怕巷子深"——深巷子里只有蜘蛛网。
2. **群发轰炸**：同一文案发 20 个群 = 被 20 个群拉黑。
3. **刷榜/刷评论**：Product Hunt 刷票会被下架，口碑崩了比没流量更惨。
4. **首日看数据焦虑**：首日数据只用来"找 bug 和记反馈"，不用来"判断生死"，判断生死看第 7 天复盘。
5. **承诺 roadmap**："下周就上 XX 功能"——说到做不到，一次就透支信任。只承诺已排期的。

## 10. 自检与反馈

### 10.1 质检门（每次使用后自查）

- [ ] launch.md 里推文/PH 文案/落地页大纲是"直接能用"的成品，还是提纲？提纲 = 不合格。
- [ ] 评论区预置回复 ≥ 5 类了吗？
- [ ] 首日清单精确到小时了吗？
- [ ] 7 天复盘计划里有"四个数+一个结论"吗？
- [ ] 宣发文案有没有绝对化承诺词？有则加限定或删掉。
- [ ] 用户评价/数字是真实的吗？编造 = 红线，直接打回。
- [ ] 跑一遍 `python3 scripts/audit/indie_audit.py --target <文档目录>`，blocker 必须为 0。

### 10.2 标准冒烟用例

输入：`"番茄钟 App，定价 ¥19/月，目标用户自由职业者"`
期望输出：launch.md 包含成品级推文、PH tagline+首条评论、
落地页大纲（含 CTA）、30 秒 demo 规划、精确到小时的首日清单、
5 类预置回复、7 天复盘计划；审计脚本 0 blocker。

### 10.3 一键提 issue

发现 bug 或有改进建议，以 `[QC] <一句话问题>` 为标题提交到
https://github.com/lhg-plugs/lhg-solopreneur/issues，
正文写清"复现步骤 → 实际表现 → 期望表现"。
